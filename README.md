# Employee Data Analysis and Visualization

## Project Overview
This project collects employee data, cleans and processes it, stores it in a MySQL database, generates Excel reports, and presents insights through a Power BI dashboard.

## Modules
- **Data Collection:** Collect employee details using Python Tkinter.
- **Data Cleaning:** Clean and process data using Pandas.
- **Database Storage:** Store employee data in MySQL.
- **Excel Reporting:** Export cleaned data to Excel.
- **Data Visualization:** Analyse salary, gender distribution, and city-wise employee data using Power BI.

## Technologies Used
Python | Tkinter | Pandas | MySQL | Excel | Power BI

## Project Files
- `project.py` – Python application code.
- `Employee_dashboard.pbix` – Power BI dashboard.
